# The kernel's entry: `entry`

The kernel's entry of a request (_l'ingresso_; EXT-6, F7, F8, PER-5, PER-25): each envelope collected at a mailbox of the node goes, opened by the face of the node's user at that mailbox, to the persona it names, to the kernel or, routed, to an extension; or the node stays silent; a response goes to the request it names. Every request answered is answered on the bond of the `Caller`'s key; a request from a face with no bond gets nothing back. Nothing happens in silence: what the entry does not take, the kernel's trace keeps (EXT-6), and what a tree closes, the tree's trace (PER-14), both for the user of the node (F6).

Written in part 13.2 (Claude, 20 Nov 2026); proved in part 13.3. The persona trees it serves and auth's lookups: [`persona/README.md`](../../../domains/src/persona/README.md), [`auth/README.md`](../../../domains/src/auth/README.md).
